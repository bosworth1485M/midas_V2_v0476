The minimum content standard (important)

As long as you maintain these sections, the documents are enough.

PROJECT_STATUS.md must always include:

Latest completed version

List of validated active guards (with pointer to ledger)

Dominant remaining failure classes (TWCS-proven)

What has been explicitly rejected

Next planned version (hypothesis only)

If those 5 things are present, I’m fully oriented.

ACTIVE_GUARDS_LEDGER.md must always include:

Each guard’s purpose

Failure class it blocks

When it should be ON / OFF

Known side effects

Exact A/B procedure

If a guard is missing from this file, it is treated as nonexistent.
