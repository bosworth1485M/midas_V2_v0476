Document 2 — Handover Document for v0.8.1.0.5 (Next Version)
TWCS Phase 3 (Part 3): 1m + 1s PNG Renderer
1. Starting Context

As of v0.8.1.0.4:

We now have 1-minute and 1-second context windows embedded in snapshot JSONs.

These snapshots provide pre- and post-trade microstructure context.

No visualization exists yet.

The next major milestone is visual candle rendering.

2. Purpose of v0.8.1.0.5

Add a PNG renderer that generates TWCS images for each trade, combining:

1-minute context

1-second context

Entry/exit markers

Optionally VWAP line

Optionally MACD histogram preview (not required in this version)

These PNGs will be stored alongside the snapshot metadata inside each trade’s folder.

3. Scope of v0.8.1.0.5

In-scope:

Add a new module:

src/midas_v2/plotting/twcs_plotter.py


Implement a function, e.g.:

def plot_twcs_snapshot(snapshot: dict, out_path: str) -> None:


Read from:

snapshot["candles_1m"]

snapshot["candles_1s"]

Entry/exit times

VWAP if available

Render a figure with:

Top panel: 1-minute candles (pre/post window)

Bottom panel: 1-second candles (detailed microstructure)

Save PNG:

trade_snapshot_entry.png
trade_snapshot_exit.png


Integrate plotter into backtester (behind a flag):

Flag name: --plot-twcs

Default: OFF

Later versions may auto-enable for debugging.

Out-of-scope:

Any trading logic

Indicator changes

Strategy decisions

Database work

Scoring or ML layers

Any UI changes

This version is visual-only.

4. Required Additions in Backtester

Where TWCS snapshots are created (entry and exit), after writing the JSON:

if params.plot_twcs:
    plot_twcs_snapshot(entry_snapshot, out_png_path)


out_png_path should be placed in the same folder as the JSON snapshots.

5. Design Requirements for Plotter

The PNG must show:

5.1 1-Minute Panel

OHLC bars from the 1-minute window.

Color-coded up/down bars.

Vertical line at the trade timestamp.

Label:

“Entry” if entry snapshot

“Exit (TP)”

“Exit (SL)”

5.2 1-Second Panel

OHLC bars from the second-level window.

Visual highlight around the exact second of trade execution.

Optional: VWAP line if included in snapshot.

Optional: volume bars (if snapshot contains volume).

5.3 File layout

PNG should be typically 1200×800 or similar.
