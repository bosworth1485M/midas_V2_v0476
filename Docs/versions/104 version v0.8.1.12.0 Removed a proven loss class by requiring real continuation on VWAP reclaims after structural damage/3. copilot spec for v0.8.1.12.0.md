------------------------------------------------------------
When a blocked-candidate event occurs, write ONE JSON file.

Required fields:
- version: "v0.8.1.13.0"
- date: date_str
- symbol: sym
- ts: candidate timestamp string (use the same variable used in the WHY log for that block,
      typically candidate_ts)
- reason: short reason string (see Reason mapping below)
- reject_key: the same reject_key used for early_reject_logged
- i: integer bar index at the moment of the block

Bar window (small, deterministic):
- N = 10
- Include completed bars: indices max(0, i-N) .. i-1

For each bar in the window, store:
- idx
- ts (only if available on bar object; otherwise omit)
- o, h, l, c, v

VWAP (optional, only if already available in-scope):
- If vwap_map exists in this scope, include vwap for each bar using vwap_map[idx].
- If vwap_map does NOT exist, omit VWAP (do NOT recompute it here).

This must be read-only. Do not mutate bars.
