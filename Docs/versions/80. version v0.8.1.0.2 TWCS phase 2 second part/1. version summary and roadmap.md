2.3. Indicators Implemented (Final Set for This Version)
✔ 1. green_streak

Counts consecutive green candles up to entry/exit.
Helps detect micro continuation vs hesitation.
Validated across COMM, PHGE, MYGN.

✔ 2. vwap

Volume-weighted average price calculated up to snapshot time.
Provides baseline trend context.

✔ 3. vwap_slope_bps

Local VWAP trend direction measured in basis points over the last 3 candles.
Extremely effective for distinguishing strong vs weak trends.

✔ 4. macd_hist (short-window version)

Short-window MACD histogram using EMA (12, 26, 9), computed on available candles.
Returns momentum strength even within an 11-bar window.

✔ 5. macd_slope

Slope of the short-window MACD histogram.
Captures acceleration/deceleration of momentum.

4. Proposed Momentum Score Formula (for v0.8.1.0.4 or v0.8.1.0.5)

Your system now has all the atomic parts needed for a “momentum score”.

Here is the recommended formula:

Momentum Score (0–100)

Let:

GS = normalized green_streak (0–3 → 0–20 points)

VW = vwap_slope_bps (clamped at ±150 → scaled to –30 to +30 points)

MH = macd_hist (scaled: hist * 400 → approx –20 to +20 points)

MS = macd_slope (scaled: slope * 1500 → approx –20 to +20 points)

Then:

momentum_score_raw = 
    (GS_norm * 1.0) +
    (VW_norm * 1.0) +
    (MH_norm * 1.0) +
    (MS_norm * 1.0)

momentum_score = clamp( 50 + momentum_score_raw , 0, 100 )


This produces:

70–100 → strong continuation entries

40–70 → mixed setups

0–40 → weak / dangerous setups
