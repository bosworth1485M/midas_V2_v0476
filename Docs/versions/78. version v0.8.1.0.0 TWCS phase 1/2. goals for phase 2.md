For entry \& exit metadata:

VWAP at the entry bar.

VWAP slope over last few bars (in bps).

MACD histogram and slope.

Green streak count and maybe a simple descriptor of last few candles.

The idea is not to fully redesign indicators yet, but to start logging what the strategy actually saw at entry/exit.
