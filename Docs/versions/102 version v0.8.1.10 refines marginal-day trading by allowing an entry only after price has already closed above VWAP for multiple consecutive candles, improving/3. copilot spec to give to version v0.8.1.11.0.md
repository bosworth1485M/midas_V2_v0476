GOAL (EXACT)
------------------------------------------------------------
Refine the marginal-day VWAP acceptance rule so that marginal entries require
CONFIRMED VWAP ACCEPTANCE within a short recent window, rather than requiring
two strictly consecutive candles immediately before entry.

This change must:
- Preserve the removal of early 09:30 marginal junk trades (GRI / IBO / NAOV / BON / CNEY class)
- Restore legitimate delayed marginal continuations (JNVR-type)
- Preserve all previously correct behavior outside marginal days

NEW RULE TO IMPLEMENT (EXACT)
------------------------------------------------------------
Rule name (for discussion only):
"MARGINAL VWAP ACCEPTANCE — WINDOWED (2 of last 3)"

When this rule applies (MANDATORY CONDITIONS)
Run this rule ONLY when ALL are true:

A) require_day_follow_through == True
B) close_gt_vwap_count == 1          (marginal day)
C) day_trade_count < 1               (marginal trade still available)
D) Entry is otherwise being considered at bar index i:
   - position is None
   - pending_entry is None
   - effective_day_gate_failed == False
   - immediately before the combined entry condition calling:
     strat.should_enter(bars, i)

If any condition A–D is false, DO NOT run this rule.

------------------------------------------------------------
WINDOWED ACCEPTANCE LOGIC (CORE CHANGE)
------------------------------------------------------------
Let i be the index of the candidate entry bar.

1) If i < 3:
   - FAIL CLOSED
   - Reject entry attempt for this bar

2) Define the acceptance window:
   - Examine the three most recent completed candles:
     indices: i-1, i-2, i-3

3) For each candle k in {i-1, i-2, i-3}, define:
   - green_k = (close_k > open_k)
   - above_vwap_k = (close_k > vwap_k)

4) Acceptance condition:
   - At least TWO of the THREE candles must satisfy:
       green_k == True AND above_vwap_k == True

5) If fewer than two candles satisfy both conditions:
   - Reject the entry attempt for this bar

------------------------------------------------------------
VWAP CALCULATION (MANDATORY — DO NOT DEVIATE)
------------------------------------------------------------
Do NOT rely on bar.vwap.

Compute VWAP incrementally using PV/V:

- tp = (h + l + c) / 3.0
- cum_pv += tp * v
- cum_v  += v
- vwap_k = cum_pv / cum_v  (only if cum_v > 0)

Loop bounds (OFF-BY-ONE PREVENTION):
- The VWAP accumulation loop MUST process bars 0..i-1 inclusive
- Use: for k in range(i):

Fail-closed behavior:
- If VWAP cannot be computed for any of i-1, i-2, or i-3 (cum_v <= 0),
  treat that candle as NOT accepted (do NOT count it)
