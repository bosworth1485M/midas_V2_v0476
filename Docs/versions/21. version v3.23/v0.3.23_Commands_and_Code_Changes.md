## 3) Code & Config Changes (Diff-Style Summaries)

### 3.1 Range summary reporting fix
**Problem:** Range summary didn’t aggregate per-day results correctly.  
**Change:** Read `out/YYYYMMDD/<Scenario>/results_YYYY-MM-DD.csv` per day; aggregate; then write range summary.

**Pseudo-diff:**
```diff
- daily_files = glob.glob(f"out/{day}/{scenario}/summary_only_{day}.txt")
- # parse summary-only lines (fragile)
+ daily_files = glob.glob(f"out/{day}/{scenario}/results_{day}.csv")
+ # read structured CSVs and aggregate metrics
+ df = pandas.concat([pandas.read_csv(f) for f in daily_files], ignore_index=True)
+ wr = (df['outcome'] == 'TP').mean() * 100
+ pnl_total = df['pnl'].sum()
+ write_range_summary(scenario, start, end, wr, pnl_total, len(df))
```

### 3.2 Rising green candles gate (enabled)
**Goal:** Enforce **3 consecutive rising green candles** as a momentum gate.  
**Config:** `rise_bars=3` (on).  
**Implementation note:** Checked in the signal builder before entry triggers.

**Pseudo-diff:**
```diff
- rise_bars = config.get("rise_bars", 0)
- if rise_bars and not candles.is_rising(n=rise_bars):
-     pass
+ rise_bars = config.get("rise_bars", 3)  # default ON in v0.3.23
+ if not candles.is_rising(n=rise_bars):
+     return NO_TRADE
```

### 3.3 MACD histogram gate (disabled for now)
**Goal:** Keep complexity low until August baseline is replicated.  
**Config:** `macd_rise_bars=0` (off).  
**Implementation note:** The MACD line/signal is still used; only histogram-rise gate is disabled.

**Pseudo-diff:**
```diff
- if cfg.macd_rise_bars > 0 and not macd.histogram_is_rising(cfg.macd_rise_bars):
-     return NO_TRADE
+ # macd histogram gate disabled in v0.3.23
+ if cfg.macd_rise_bars and cfg.macd_rise_bars > 0:
+     pass  # gate bypassed
```

### 3.4 Universe builder hygiene (topgappers)
**Goal:** Always write the per-day universe and update the active universe path.  
**Notes:** Use `parse_known_args`; remove accidental reliance on `--no-write` paths.

**Pseudo-diff:**
```diff
- parser.add_argument("--no-write", action="store_true")
- if args.no_write:
-     print("[UNIVERSE] preview only")
- else:
-     write_universe(active_path, symbols)
+ write_universe(per_day_path, symbols)       # e.g., data/universe_topgappers_YYYY-MM-DD.txt
+ write_universe(active_universe_path, symbols)  # current active universe for runners
```
