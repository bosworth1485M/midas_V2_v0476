## Why August WR Differs From Earlier ~63% (No Engine Bug)
1) **Universe drift (primary):** different symbols per day → different outcomes.  
2) **Analyzer inputs:** earlier runs mixed `out/auto/...`; base‑only uses only per‑day canonical files.  
3) **Driver order:** summarizing before rebuilding per‑day files yielded “0 trades”; safe driver fixes this.  
4) **Scenario creep (minor):** small param changes move WR; we restored August‑baseline D/E before replays.

**Conclusion:** differences are explained by **inputs & workflow**, not the engine.

## What “tight” means in successful runs (and why it wins)
**Tight** = smaller, higher‑quality list each day:
- **Catalyst filter ON** (real news): FDA/Phase/trial, contract wins, earnings beat/raised guidance, upgrades.  
  Drop: ATM/offering/dilution, reverse split, Nasdaq deficiency, going concern, resignations, fluff PRs.
- **Opening RVOL gate** ≥ **1.5** in first 10–15 minutes (can test 2.0 in choppy months).
- **Top‑N cap** after catalyst: **N=3–5** by default (preserves focus).  
- **Ross guards in scenarios** (already in D/E): Price 1–20; Gap 10–40; min_pm_vol ≥ 30–50k; Gate 5–10 (D) / 10–15 (E); EMA+VWAP+MACD on (D rise_bars=2, E rise_bars=3); TP/SL ≈ 2.0/2.5.

**Observed impact (other projects):**
- **WR:** +5–12 percentage points over raw restricted baselines; many months reach **≈60–65%**.  
- **Expectancy:** larger lift (fewer tail losers).  
- **Trade count:** 30–70% fewer trades (higher quality).

### When to broaden (safely)
- Only in **“hot”** tape: strong breadth / index up / many true catalysts.  
- Use a **graduated cap**: increase to **N=6–8** only if ≥4 **A‑grade** catalysts pass RVOL (FDA/contract/beat).  
- Never broaden on days full of fluff PRs or financing chatter.

## High‑Impact Add‑Ons (after the core stack)
1) **1‑second entry trigger (hybrid)**
   - Fetch 1‑second bars for first 15–30m; trigger entry on 1s (with RVOL gate passed), then manage on 1m.  
   - Effect: slightly better WR; clearer entries; better PnL distribution.

2) **Multiple trades per ticker (controlled)**
   - `max_trades_per_symbol=2`, `cooldown_minutes=15`, `reentry_requires_new_setup=true` (new reclaim/structure).  
   - Helps on strong catalyst trend days; can hurt if overused.

3) **Risk‑based sizing (“Kelly‑lite”)**
   - Baseline fixed dollar risk (e.g., $50) → position size = risk/(entry×sl%).  
   - **Scale +20–30%** on **A‑grade** catalysts (catalyst+RVOL+clean structure); **−20–30%** on marginal setups.  
   - Add **drawdown throttle** and **daily loss cap**.

4) **One extra scenario (kept simple)**
   - **ORB** (opening range breakout) with same catalyst + RVOL gates.

## Glossary (consistent terms)
- **Canonical per‑day output (“canonical”)** — official per‑day CSV: `out/YYYYMMDD/SCENARIO/results_YYYY-MM-DD.csv` (single source of truth).  
- **Base‑only analysis** — compute N/WR/PnL from canonical per‑day files only (ignore `out/auto`).  
- **Raw top‑gappers** — `data/universe_topgappers_YYYY-MM-DD.txt` (no catalyst filter).  
- **Catalyst universe** — `data/catalyst/universe_YYYY-MM-DD.txt` (news‑scored + optional top‑N).  
- **Safe driver** — `scripts/run_range_safe.py` (runs per‑day backtests before summarizing).  
- **Universe drift** — symbol‑set differences across runs that change outcomes.
