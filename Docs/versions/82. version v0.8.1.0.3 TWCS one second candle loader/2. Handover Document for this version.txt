# Handover to Midas_V2 v0.8.1.0.4
TWCS Phase 3 (Part 2): Wire 1-Second Candles into Snapshots
1. Starting Context

As of v0.8.1.0.3:

The system has a fully working, safe, standalone 1-second loader.

No wiring exists yet into:

Entry TWCS block

TP exit TWCS block

SL exit TWCS block

This version (v0.8.1.0.4) will attach 1-second candles into actual TWCS snapshots.

We must keep this version as small and controlled as v0.8.1.0.3.

2. Objective of v0.8.1.0.4
✔ Modify backtester TWCS blocks to include 1-second windows

Specifically:

A. Entry Snapshot

Inside the existing TWCS entry snapshot logic, add:

from midas_v2.dataio.twcs_second_loader import load_twcs_second_window

candles_1s, meta_1s = load_twcs_second_window(
    symbol=sym,
    date_str=date_str,
    target_time_str=entry_time_iso,
    window_before_seconds=60,
    window_after_seconds=0,
)

snapshot["candles_1s"] = candles_1s
snapshot["window_size_1s"] = meta_1s["window_size_1s"]
snapshot["window_before_1s"] = meta_1s["window_before_1s"]
snapshot["window_after_1s"] = meta_1s["window_after_1s"]

B. TP Exit Snapshot

Add the identical block using:

exit_time_iso

candles_1m_exit context if needed

C. SL Exit Snapshot

Same as TP block but in the SL code path.

3. Constraints (Very Important)

Modify any trading logic

Modify indicators

Modify scenario configuration

Add any new fields except candles_1s + metadata

Change strategy behavior

Introduce PNG rendering

v0.8.1.0.4 must be purely wiring, no functional logic changes.
