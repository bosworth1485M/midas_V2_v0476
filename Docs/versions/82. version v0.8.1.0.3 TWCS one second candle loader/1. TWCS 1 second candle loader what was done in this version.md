# Midas_V2 — Version v0.8.1.0.3
TWCS Phase 3 (Part 1): 1-Second Window Loader
1. Version Purpose

The objective of v0.8.1.0.3 was to introduce a dedicated data loader for 1-second candles used by the TWCS (Trade Window Context Snapshot) system. This version focuses only on adding the loader itself — no wiring, no strategy or snapshot changes, preserving the incremental, slice-by-slice architecture.

This is the first half of TWCS Phase 3.

2. Files Added / Modified
✅ Added File

src/midas_v2/dataio/twcs_second_loader.py

This is the core artifact of v0.8.1.0.3.

Responsibilities of this module:

Safely load 1-second TWCS candle windows around a target timestamp.

Accept flexible timestamp formats (YYYY-MM-DDTHH:MM:SS, YYYY-MM-DD HH:MM, HH:MM, etc.).

Resolve the CSV path:

data/samples/sample_1s_{date_str}_{symbol}.csv


Handle missing files gracefully:

Log a warning

Return (empty_list, metadata)

Handle CSV parse errors safely:

Never crash

Skip malformed rows

Return a standardized candle structure:

{
  "t": "ISO timestamp",
  "o": float|None,
  "h": float|None,
  "l": float|None,
  "c": float|None,
  "v": float|None,
  "idx_from_entry": int   # seconds offset from target_time
}


Perform correct time-window filtering:

window_before_seconds (default 60)

window_after_seconds (default 0)

Sort candles by timestamp in ascending order.

Provide metadata:

{
  "window_size_1s": N,
  "window_before_1s": 60,
  "window_after_1s": 0
}


Design constraints fully met:

Pure data-loading module

No side effects besides logging

No dependency on backtester or indicators

Fully defensive error handling

Backtester remains untouched in this version
