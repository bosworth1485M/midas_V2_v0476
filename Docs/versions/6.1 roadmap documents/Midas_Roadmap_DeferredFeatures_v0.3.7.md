# Midas Project Roadmap – Deferred Features

**Date:** 2025-09-07  
**Version Context:** v0.3.7-cleanup  

---

## Overview
This roadmap table tracks major **deferred features** for the Midas_V2 project.  
Each entry shows purpose, status, and milestone timing.

---

## Deferred Features Table

| Feature | Purpose | Status | Target Version |
|---------|---------|--------|----------------|
| Hybrid Router (A–E) | Combine scenarios with precedence (e.g., E→D→B), 1 trade per symbol | Deferred until scenarios tuned | v0.3.9+ |
| Rolling 3-Month WR Tracker | Track long-term consistency (smooth good/bad months) | Deferred milestone | v0.3.10+ |
| Adaptive Sizing | Risk more on higher-expectancy trades, Kelly-lite approach | Planned, not started | v0.4.x |
| Broker Abstraction | Switch between Alpaca, Lightspeed, etc. via config | Planned, not started | v0.5.x |

---

## Notes
- All features are postponed until **baseline scenarios are stable**.  
- Each will be documented with MD + PDF when introduced.  
- Roadmap ensures we don’t lose sight of long-term goals while focusing on current stability.
