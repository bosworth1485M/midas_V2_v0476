# v0.3.21 Plan

## Scope
- **Catalyst quality filter:** require A or better (`--min-grade 2`), no B-fill by default.  
- **Opening RVOL gate:** add `--min-rvol-open` (default 1.5), comparing first 10–15m volume vs prior day same window.  
- **Score-based sizing (framework):**  
  - A → 1.0× risk  
  - A+ → 1.5× risk  
  - Super-A → 2.0× risk  
  - Still capped by per-trade and daily risk limits.  
- **Denylist hygiene:** drop warrants and non-targets (patterns like `*.WS`).  
- **Docs & summary upgrades:** summarizer adds footer with run parameters (min_grade, topn, rvol gate).
