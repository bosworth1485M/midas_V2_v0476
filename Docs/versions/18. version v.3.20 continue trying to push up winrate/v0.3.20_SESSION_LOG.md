# v0.3.20 Session Log & Fixes

## Date
2025-09-17

## Summary of Fixes
- **Negative-headline exclusion:** ensured stocks with bearish headlines (e.g., "revenue falls") are excluded.  
- **Log clarity:** enrich logs now show `[DROP NEG]` instead of `[KEEP]` for negative headlines.  
- **Sanitize catalyst_scores CSV:** negative headlines rewritten to `score=0` on disk.  
- **Magnitude-aware scoring:** parsed % changes in revenue/guidance from headlines.  
  - Example:  
    - 0–14% → score 1.0 (B)  
    - 15–34% → score 2.0 (A)  
    - 35–59% → score 2.5 (A+)  
    - 60%+ → score 3.0 (super-A)  
- **Debug lines:** `[MAG]` lines show upgrades when % detected.  
- **One-pager summary:** each run writes `out/YYYYMMDD/_final/summary_only_YYYY-MM-DD.txt`.
