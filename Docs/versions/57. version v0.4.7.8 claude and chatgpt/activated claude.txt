3 ChatGPT + Claude — two-model workflow (simple & safe)

Roles

Tool	Role	Typical Tasks
ChatGPT (designer/architect)	Writes specs, change requests, acceptance criteria, and verification steps. Guards constraints so features stay aligned with the profitability roadmap.	Design, planning, validation
Claude (editor/generator)	Performs readability passes, creates small helpers, and drafts tests from clear prompts.	Refactor, docstrings, test drafts

Daily loop

Define a tiny scope with ChatGPT (what file/block, allowed/forbidden changes).

Claude executes — returns full file or small diff.

Verify with single-day or golden-day runs; only then commit + tag.

Repeat with another tiny scope.

When to use each style

Whole-file swap (preferred for readability): fastest; Claude returns entire cleaned file → diff locally → if identical behavior, replace and tag.

Patch/diff mode (optional for audit): use when editing critical blocks and you want a record under patches/.

4 Do we recommend the patching approach?

Optional — useful for critical code and auditability, not needed for simple readability.

Use patching when:

You want a reviewable diff touching fragile logic.

You need an instant revert path and a logged Change Request.

Use whole-file swap when:

The change is cosmetic only.

You confirmed via diff that no logic changed.

You want speed without patch overhead.

v0.4.7.8 used the whole-file swap approach and passed sanity tests.
