DOCUMENT 1 — Very Detailed Technical Account of v0.8.1.0.8
Version Goal

The goal of v0.8.1.0.8 was to experimentally evaluate whether 1‑second microstructure data could be used as a strict confirmation gate for minute‑based Cameron‑style entries, specifically:

Only allow trades when recent 1‑second price action confirms a breakout via a strict rule (Definition A).

This version was explicitly framed as a hypothesis test, not a tuning exercise.

Core Hypothesis (Definition A)

Definition A – “Breakout + Hold” (STRICT):

At the moment a minute‑bar entry would normally trigger:

Look back over the last 30 seconds of 1‑second candles.

Compute:

prior_high = max(high) in that 30‑second window

breakout_level = prior_high * (1 + breakout_bps) where breakout_bps = 10

Pass the gate only if:

Condition 1: At least one 1‑second candle high reaches or exceeds breakout_level

Condition 2: The latest 1‑second close at or before entry time T is also ≥ breakout_level

If any data is missing, malformed, or ambiguous → fail closed.

This gate was intentionally conservative and designed to test whether strict microstructure confirmation aligns with anticipatory minute entries.

Release State / Default Behavior (Important)

Before tagging and archiving v0.8.1.0.8, the following release-state conditions must hold:

In config/scenarios.json, Scenario B must have:

"micro_expansion_gate": false

Definition A (microstructure expansion gate) is retained for reference and future experimentation, but is disabled by default.

With the gate OFF, baseline strategy behavior (trade count, entry logic, exits) is unchanged from pre-v0.8.1.0.8 behavior.

This ensures that v0.8.1.0.8 is a clean, non-regressive release, with experimental logic present but inactive.

Conclusion of v0.8.1.0.8

Definition A is too strict for anticipatory minute‑based entries.

Key insight:

Successful trades often begin while 1‑second pressure is building — not after strict breakout confirmation has occurred.

This version therefore successfully rejected a hypothesis and validated the 1‑second infrastructure.
