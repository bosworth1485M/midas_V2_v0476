Version Intent

v0.8.1.0.9 — Rising 1‑Second Pressure Gate (Definition B)

This version introduces a soft pressure gate that aligns with anticipatory minute entries.

High‑Level Rule (Definition B)

At minute entry index i for symbol S:

Load 1‑second candles for symbol S

Normalize entry time T

Look back over last pressure_window_s (default: 20–30s)

Compute pressure metrics

Pass gate if pressure is rising

Suggested Initial Definition B (Minimal)

Definition B1 — Rising Highs Count

Pass gate if:

In the last pressure_window_s seconds

There are N or more consecutive higher 1‑second highs

Where:

pressure_window_s = 20

min_rising_highs = 3

This is intentionally simple and visually intuitive.
